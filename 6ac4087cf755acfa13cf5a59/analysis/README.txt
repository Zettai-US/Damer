arVM manuscript: layout and analytical companion
================================================

The manuscript uses the unmodified official USENIX style from:
https://www.usenix.org/sites/default/files/usenix2019_v3.sty
Format reference checked 2026-10-06:
https://www.usenix.org/conference/osdi27/requirements-authors

Build: make
Recompute analytical sensitivity data: make model
Check manuscript page budget and typography: make check
Native CXL evidence and reproduction: experiments/README.txt
Live CXL sharing/retention: ../workloads/agent_sharing/README.md from paper root
Rebuild archived live figures and numeric claims: make profile

Requirements: GNU Make 4.3+, TeX Live, Python 3, numpy, matplotlib and Poppler.
The submitted-style document has 12 body pages and separate references.
check_format.py validates Letter paper, a 7 x 9 inch text block, 0.33 inch gutter,
10/12 pt type, embedded fonts, resolved references and the body-page budget.
The PDF ink check allows 3 points for font descenders and standard microtype
protrusion; the underlying TeX dimensions are checked exactly within rounding.

model.py is a closed-form analysis, separate from the measured CXL experiments.
analytical_model.tex retains its derivation as a supplement. The main paper
now uses that space for actual multi-round agent traces and retention ablation;
it does not replace the native component measurements with simulated data.
It exports 412 calculated rows plus three sensitivity figures. Bandwidths,
mapping costs, sizes and probabilities are assumed parameters, not fitted data.
No random samples or measured end-to-end speedups are generated by this script.

Chart/data map
--------------
capacity.csv: 21 overlap fractions x four reader counts (84 rows), with payload
savings excluding metadata, caches and transient producer allocations.
service.csv: 41 sizes x four scan counts (164 rows), comparing aggregate pool
read and local scan service demand. Destination writes, cache reuse, queueing,
resource overlap and NUMA effects are excluded.
prefetch.csv: 41 use probabilities x four lead times (164 rows), with exposed
control cost 0.2 transfer durations and no interference.
summary.json preserves exact illustrative examples. The analytical plots are
reproducible companions; the main PDF uses the separate measured figures.

Formatting checks do not establish research novelty or publication readiness.
The manuscript explicitly states the implemented subset and measured workload
scope. The authors must assess the remaining integration and evidence gaps.
